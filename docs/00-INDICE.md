## 🚦 Por dónde empezar (ahora mismo)

1. Lee [Visión y MVP](01-vision-y-mvp.md) para tener claro el norte.
2. Revisa el [Product Backlog](02-product-backlog.md) y ajústalo a tu gusto.
3. Ejecuta el **Sprint 0** del [Plan de Sprints](03-plan-sprints.md):
   crear el repo en GitHub, el tablero en GitHub Projects y el esqueleto del proyecto.
4. Recién ahí empiezas a codear, sprint por sprint.

## 🎯 Objetivo del proyecto

Tener un proyecto **estrella** para el portafolio y GitHub, que demuestre:
- Desarrollo **fullstack** (front + back + base de datos).
- Manejo de **Scrum** (backlog, HU, sprints, tablero).
- Un caso de negocio **real y peruano** (inventario para PYME).
